跨裝置同步

資料在這支手機上先用 AES-256 加密才上傳，GitHub 只看得到密文。 預設就存回這個 App 自己的 repo，放在獨立分支，不會干擾網站部署。 同步檔裡有記憶、個性、臉部檔案與備用密碼的雜湊，但沒有 API 金鑰—— 那個放進公開檔案會被爬蟲撿走，所以每台裝置各自填。

手動設定（平常不用碰）

留空就好：新裝置掃臉就能接手，不用打任何東西。 填了的話安全性更高（同步檔變成只有你解得開），但每台新裝置都要輸入一次。 無論填不填，API 金鑰都不會放進同步檔。
